## 3.1 The Python Interpreter

As was mentioned earlier, Python is an interpreted programming language. What this means is that, unlike a compiled language such as C, which needs to be compiled into separate, machine readable code before it can be executed, Python comes with an interpreter which runs a Python program by reading and executing code line by line. 

Matlab

To run Python code, we can either create a Python file, write all of our code in that file, and then run it with the "python3 file_name_here" command, or we can invoke the interactive Python interpreter and write code line by line in the command line. To invoke the interactive Python interpreter, simply run the ``python3`` command in your terminal, and an interactive prompt will pop up where you can then write Python code.

The interactive interpreter is not the main place you will run code, but it does have its uses. Its main use is going to be for on-the-fly programming, and as you learn Python, it can be pretty useful for quickly testing out how a certain object behaves.
